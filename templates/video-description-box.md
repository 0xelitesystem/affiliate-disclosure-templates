# Video: description box disclosure

## Use when

Always. The description box should reinforce whatever spoken or visual disclosure was in the video.

## Placement

ABOVE THE FOLD. The description box is collapsed by default; only the first ~120 characters show. The disclosure must be in those visible characters, not below the "...more" cutoff.

## Templates

### Affiliate-only video

```
Some links below are affiliate links. I earn a small commission at no extra cost to you. Full picks and timestamps below.

[your normal description here]
```

### Sponsored video

```
This video was sponsored by [BRAND]. All opinions are my own. See more about [PRODUCT] at [LINK].

[your normal description here]
```

### Mix of affiliate and sponsored

```
Sponsored by [SPONSOR]. Other links in this description may be affiliate links, I earn a commission if you buy through them at no cost to you.

[your normal description here]
```

### Gifted product

```
[BRAND] sent the [PRODUCT] for free. They did not pay for this video and have no approval over content.

[your normal description here]
```

## What NOT to do

- Don't put the disclosure at the bottom of the description (below the "...more" fold)
- Don't substitute hashtags (`#ad`, `#sp`) for actual disclosure language in a description box; you have the space to be specific
- Don't link to a separate disclosure page; the FTC requires the disclosure to be visible on the same content
