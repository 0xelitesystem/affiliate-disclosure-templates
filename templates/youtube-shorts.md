# YouTube Shorts disclosure

## Constraints

- 60 seconds max (sometimes longer; varies)
- Vertical 9:16 aspect ratio
- Limited description visibility
- Viewers swipe quickly; spoken disclosure must be FAST

## Templates

### Spoken (in first 3 seconds, before any recommendation)

> "Affiliate link in description, just so you know."

> "Quick heads-up: this is sponsored by [BRAND]."

> "[BRAND] sent me this free, opinions are mine."

### On-screen text (visible for at least 3 seconds, in the safe area)

> Affiliate link in description

> Paid promotion

> Free sample, opinions are mine

### Description (Shorts descriptions are short, so be terse)

```
Sponsored by [BRAND]. Code: [CODE]. Link: [LINK]
```

```
Affiliate link below. I earn a commission, costs you nothing extra.
```

## Why short-form is harder

The FTC's bar (clear, conspicuous, before the recommendation) is the same on Shorts/Reels/TikTok as on long-form. The 30-60 second format means the disclosure has to be even faster and visually inescapable. Don't skip it because the format feels casual.
