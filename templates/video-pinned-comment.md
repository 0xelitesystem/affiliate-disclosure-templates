# Video: pinned comment disclosure

## Use when

A pinned comment is supplementary, not a replacement for the description-box disclosure. Use a pinned comment when:

- The video already has spoken + description disclosure, AND
- You want to surface affiliate links / coupon codes prominently

## Templates

### Affiliate links pinned

```
Here are the products I mentioned + my affiliate links (I earn a small commission, costs you nothing extra):

- [PRODUCT 1]: [LINK]
- [PRODUCT 2]: [LINK]
- [PRODUCT 3]: [LINK]

Honest reviews, not sponsored, I bought these myself.
```

### Sponsor coupon pinned

```
Today's sponsor is [BRAND]. Use code [CODE] for [DISCOUNT]: [LINK]

Full disclosure in the video at [TIMESTAMP].
```

## What NOT to do

- Don't make a pinned comment the ONLY disclosure. Pinned comments can be unpinned, edited, or hidden by viewers. The video itself and the description must carry the disclosure.
- Don't write the pinned comment as if it's from a viewer ("Loved the video! Here's where to buy..."). That's deceptive.
