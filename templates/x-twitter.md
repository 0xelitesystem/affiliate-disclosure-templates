# X / Twitter disclosure

## Single tweet

```
Loving the new [PRODUCT] from @brand. #ad

[link]
```

OR

```
Sponsored: my honest take on [PRODUCT] from @brand. [link]
```

## Thread (multi-tweet)

- First tweet has the disclosure
- Don't disclose only in tweet #5

```
1/ Sponsored thread - [BRAND] paid me to share what I think of [PRODUCT]. Going to walk through pros, cons, and who it's for.

2/ ...
```

## Reply / quote with affiliate link

```
Great find. Affiliate link if you want the deal: [link]
```

## What doesn't work on X

- Disclosure ONLY via X's "Promoted" tag (which is for paid Twitter ads, not influencer disclosure)
- Disclosure in your bio instead of the tweet
- Disclosure as a tweet replying to your own tweet ("oh by the way that was sponsored")
