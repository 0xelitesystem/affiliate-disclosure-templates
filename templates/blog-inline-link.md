# Blog: inline link disclosure

## Use when

Specific links in the post are affiliate links and you want per-link clarity beyond the top-of-post disclosure.

## Templates

### Asterisk + footnote

```
We recommend the [Product Name](https://example.com/affiliate-link) (*affiliate link).

*Affiliate link: I earn a commission if you buy through this link at no cost to you.
```

### Inline parenthetical

```
The best option here is the [Product Name](https://example.com) (affiliate link).
```

### Tag prefix

```
[*Affiliate*] [Product Name](https://example.com)
```

## When inline disclosure is required

If you don't have a clear top-of-post disclosure covering all affiliate links, you must label each one. Inline disclosure is also good practice when:

- The post is very long (top disclosure scrolls off-screen)
- Different links have different relationships (some affiliate, some not)
- The post is RSS-distributed and the top disclosure may not travel with each link
