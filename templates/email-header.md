# Email / newsletter: header disclosure

## Use when

A newsletter issue contains sponsored content, affiliate links, or any other material connection.

## Standard header block

Place at the top, before any content:

```
Today's issue is brought to you by [SPONSOR].
[1-2 sentence sponsor pitch]
[Link]

----------

[Newsletter content begins here]
```

## Affiliate-only newsletter (no sponsor)

```
Heads up: some links in this issue are affiliate links. If you click and buy, the newsletter earns a small commission at no extra cost to you.

----------

[Content]
```

## Mixed content header

```
Today's issue: 1 sponsor segment (clearly marked), several recommendations with affiliate links, and an unsponsored deep-dive on [topic].

----------

[Content]
```

## Don't

- Don't bury the disclosure below the fold (most email clients show only the first ~100 characters in preview)
- Don't put the disclosure ONLY in the footer (footers are often clipped by Gmail "show trimmed content")
